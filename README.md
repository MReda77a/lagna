# لجنة 📝

لعبة أسئلة للقعدة من ٣ لـ ١٠ لعيبة، كل واحد من تليفونه: جاوب، بص على ورقة جارك، وخلّي بالك من المراقب.

السيرفر هو اللي بيشغّل اللعبة، وكل لعيب بيوصله اللي مسموح له يشوفه بس. يعني ورقة جارك مش بتتبعت لتليفونك غير وإنت دايس على "بص".

---

## فيه إيه جوه المشروع

```
lagna/
├── public/
│   ├── index.html      ← شكل اللعبة (الشاشات والألوان)
│   ├── app.js          ← اللي بيشتغل على التليفون: بيبعت اللي اللعيب بيعمله ويرسم اللي السيرفر يبعته
│   ├── engine.js       ← قواعد اللعبة كلها (الأدوار، البص، المراقب، الفرق، النقط، لعيبة الكمبيوتر)
│   ├── questions.js    ← بنك الأسئلة (٧ مواد)
│   ├── manifest.json   ← عشان اللعبة تتنزل على الشاشة الرئيسية زي الأبلكيشن
│   └── icons/          ← أيقونات اللعبة (١٩٢، ٥١٢، ١٠٢٤)
├── shared/room.js      ← إدارة اللجنة (دخول، خروج، صاحب اللجنة، مين يشوف إيه)
├── cloudflare/worker.js← السيرفر على Cloudflare
├── wrangler.jsonc      ← إعدادات Cloudflare
├── server/index.js     ← نفس السيرفر بس بـ Node.js (عشان تجرب على جهازك)
└── package.json
```

## ١. ارفعها على Cloudflare

### من GitHub من غير ما تكتب أوامر

1. ارفع المشروع على GitHub (من غير فولدر `node_modules`).
2. من [dash.cloudflare.com](https://dash.cloudflare.com): **Workers & Pages** ← **Create** ← **Import a repository**، واربط حساب GitHub واختار الـ repo.
3. خلي اسم المشروع **`lagna`** بالظبط (لازم يطابق الاسم اللي في `wrangler.jsonc`).
4. الـ **Deploy command** يبقى: `npx wrangler deploy` (وسيب الـ Build command فاضي).
5. دوس **Deploy**. بعد دقيقة هيديك لينك زي `https://lagna.اسمك.workers.dev`.

وأي تعديل ترفعه على GitHub بعد كده، Cloudflare بينزله لوحده.

### أو من الكمبيوتر

محتاج **Node.js نسخة ١٨ أو أحدث**.

```bash
npm install
npx wrangler login     # هيفتح المتصفح عشان تسجل دخول Cloudflare
npx wrangler deploy
```

## ٢. جرّبها على جهازك

```bash
npm install
npm start
```

افتح **http://localhost:3000**. عشان تلعبوا من الموبايلات وانتوا على نفس الواي فاي، افتح من الموبايل **http://IP-الكمبيوتر:3000**.

- `npm run cf:dev` بيشغّل نسخة Cloudflare على جهازك على **http://localhost:8787**.
- لو فتحت `public/index.html` كملف من غير سيرفر، اللعبة بتشتغل ضد الكمبيوتر بس.

---

## ٣. إزاي اللعبة ماشية

- **فردي:** في كل سؤال واحد هو المراقب والباقي طلبة، ودور المراقب بيلفّ على الكل بالتساوي. أقل عدد ٣.
- **فرق:** صفّين، كل صف ليه إجابة واحدة، وفي كل سؤال واحد بس من الصف هو الغشاش (الدور بيلفّ). المراقب هو الكمبيوتر. أقل عدد ٤.
- صاحب اللجنة يقدر يضيف لعيبة كمبيوتر لو العدد ناقص.
- اللي يخرج في نص اللعبة مكانه محفوظ: يرجع بنفس الكود أو اللينك ويكمّل بنقطه.
- أنواع الإجابة: ٤ اختيارات، صح ولا غلط، ترتيب، رقم (الأقرب يكسب)، ورأي اللجنة (الأغلبية تكسب).

---

## ٤. تزوّد أسئلة

افتح `public/questions.js` وضيف سطر في المادة اللي عايزها، بنفس شكل السطور اللي فوقه. الشرح مكتوب في أول الملف.

---

## ٥. اللي لسه مش موجود

- الأسئلة والإجابات محتاجة مراجعة منك قبل ما تنشر اللعبة.
- أرقام التوازن (وقت السؤال، رصيد المراقب، النقط) صاحب اللجنة بيظبطها من "ظبط الأرقام"، ولسه محتاجة لعب حقيقي.
- مفيش حسابات ولا حفظ نتايج بين القعدات.
